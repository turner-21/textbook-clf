# textbook-clf

AWS Certified Cloud Practitioner (CLF-C02) の学習ガイドです。1枚のHTMLファイルで、試験範囲の4ドメインをまとめています。

公開ページ: https://turner-21.github.io/textbook-clf/

## 内容

- ① クラウドコンセプト
- ② セキュリティ・コンプライアンス
- ③ クラウド技術・サービス
- ④ 請求・料金・サポート
- 全体まとめ:4ドメインの関係
- 試験直前チェックリスト

## ローカルで見る

ビルドは不要です。`index.html` をブラウザで開いてください。
